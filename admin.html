طريقة الاستخدام السريعة

  1. افتح ملف products.json من فولدر الموقع.
  2. عدّل السعر، الكمية، الصور أو الوصف.
  3. اضغط حفظ، أو حمّل نسخة جديدة.
  4. ارفع الملف على GitHub وانشر التعديل.
