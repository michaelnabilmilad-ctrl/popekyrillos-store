# تفعيل مساعد مكتبة البابا كيرلس

## ما أُضيف

- زر محادثة بالعربية داخل الرئيسية وصفحات الأقسام والمنتجات، مع بطاقات وروابط موثوقة وحوار قصير يدعم الأسئلة المتتابعة.
- Claude API مع أدوات محدودة لبحث المنتجات والأسعار والمواصفات والتوافر والسياسات.
- أدوات متابعة الطلب والتواصل تفتح الصفحات الموجودة. لا ترسل إشعارات ولا تنشئ تذاكر أو طلبات.
- تعطيل افتراضي وفشل آمن عند غياب الإعدادات، وTurnstile قبل كل سؤال، وحد 12 سؤالًا لكل IP خلال 10 دقائق، وحد يومي مشترك عبر D1.

## مصادر البيانات وحدودها

الأسعار والمنتجات تُقرأ من فرع `products-data` عبر إعدادات GitHub الحالية. عند تعطل المصدر لا يرجع المساعد إلى نسخة قديمة ليقول سعرًا غير مؤكد. قواعد الأسعار تستخدم نفس وظائف الموقع الحالية، بما فيها الفرق بين المتغير الافتراضي والاختيارات الحقيقية.

التوافر هنا **توافر الكتالوج**، وليس رصيدًا لحظيًا من Airtable. لا يضمن المساعد كمية معينة ولا يحجز مخزونًا. حالة مجهولة تظهر «التوافر يحتاج تأكيد».

السياسات تُقرأ من `policies.html` المنشور، ويظهر رابط السياسة كاملة. المواعيد أو الرسوم غير المحددة تحتاج تأكيد موظف.

متابعة الطلب تتم على `/track-order` بالتحقق الموجود بالفعل. لا يقرأ المساعد طلبات Airtable ولا يرسل بياناتها إلى النموذج. المستخدم يتحقق بنفسه في صفحة المتابعة.

## إعداد الحسابات

اشتراك Claude Pro للتطوير باستخدام Claude Code؛ التشغيل على الموقع يتطلب **Claude API** وفوترة منفصلة. أنشئ مفتاح API، واختر ID لموديل متاح في حسابك من وثائق Anthropic الحالية. لا يوجد موديل أو تسعير مفترض في الكود.

أنشئ Cloudflare Turnstile widget للموقع `popekyrillos.store`. أضف hostname بيئة المعاينة إذا كنت ستجرب عليها، واستخدم مفاتيح اختبار Turnstile الرسمية فقط في بيئة التطوير.

## الإعدادات داخل Worker

| الاسم | النوع | المطلوب |
| --- | --- | --- |
| `ASSISTANT_ENABLED` | Variable | `0` أثناء الإعداد؛ `1` بعد الاختبار |
| `ANTHROPIC_API_KEY` | Secret | مفتاح Claude API |
| `ANTHROPIC_MODEL` | Variable | معرف موديل متاح فعليًا في الحساب |
| `ASSISTANT_SESSION_SECRET` | Secret | سر عشوائي مستقل بطول 32 حرفًا على الأقل |
| `TURNSTILE_SITE_KEY` | Variable | المفتاح العام لـ Turnstile |
| `TURNSTILE_SECRET_KEY` | Secret | مفتاح التحقق السري |
| `ASSISTANT_DAILY_REQUEST_LIMIT` | Variable | الافتراضي 50 سؤالًا يوميًا؛ الحد الأقصى المسموح 1000 |

هذه الإعدادات تُضاف في Cloudflare Dashboard → Worker `popekyrillos-store` → Settings → Variables and Secrets. يحتفظ `wrangler.toml` بالإعدادات الحالية عبر `keep_vars = true`. لا تضع الأسرار في هذا الملف أو في GitHub.

توليد سر محليًا:

```bash
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

لا ترسل الناتج في محادثة؛ ضعه مباشرة في إعداد Secret.

## تهيئة D1

المشروع يستخدم قاعدة `popekyrillos-analytics` المرتبطة باسم `ANALYTICS_DB`. أضف الجدول قبل التفعيل:

```bash
npx wrangler d1 execute popekyrillos-analytics --remote --file=migrations/assistant-usage.sql
```

للتطوير المحلي، انسخ `.dev.vars.example` إلى `.dev.vars`، واستخدم `--local` بدل `--remote` في الأمر السابق. لا تستخدم قاعدة الإنتاج لاختبارات المحاكاة.

الجدول يحفظ عدادات فقط ومفاتيح IP مشتقة باستخدام hash مملح بالسر، وليس المحادثات. يُحذف القديم أثناء استقبال الطلبات المقبولة. عند غياب الجدول أو تعطل D1، تُرفض المحادثة قبل استدعاء Claude.

## البناء والاختبار والنشر

```bash
npm ci
npm run check:assistant
node --test tests/catalog-price-source.test.mjs tests/customer-orders.test.mjs tests/payment-order-submission.test.cjs tests/product-route-state.test.cjs
npm run build:cloudflare
```

انشر من مسار Cloudflare المعتاد للمشروع بعد مراجعة التعديل. أبقِ `ASSISTANT_ENABLED=0` إلى أن تضبط الأسرار والجدول. فعّل `1` في بيئة المعاينة أولًا، ثم جرّب:

1. «عندكم صليب صدر يوناني؟» و«أنبوبة رفات خشب» — تطابق السعر والصورة والرابط مع الكتالوج الفعلي.
2. سؤال تابع عن مقاس أو خامة — يستعمل سياق المحادثة الموقّع ويعيد قراءة السعر إذا سُئل عنه.
3. سياسة الاسترجاع — تطابق الصفحة الحالية ورابطها.
4. متابعة طلب — يفتح صفحة التحقق، ولا يطلب بيانات شخصية في المحادثة.
5. سؤال غير موجود أو مصدر معطل — لا يخترع بيانات؛ يعرض تعذر التحقق أو رابط الموظف.
6. أداة الموبايل ولوحة المفاتيح والإغلاق بزر Escape.

## الاستهلاك والخصوصية

الحد اليومي هنا حد **عدد أسئلة** وليس ضمان ميزانية مالية. كل سؤال قد يستدعي Claude حتى 3 مرات، بحد 700 output tokens لكل استدعاء وحمولة إدخال قصوى 90KB لكل استدعاء. ضع أيضًا ميزانية/تنبيه استخدام في حساب Claude API حسب الخيارات المتاحة في الحساب. الطلب المقبول يُحتسب حتى إذا فشلت الخدمة بعده؛ هذا يمنع الإعادة المفتوحة.

كل request لديه مهلة عامة 45 ثانية. سياق الحوار محفوظ في ذاكرة الصفحة كتوقيع HMAC صالح 30 دقيقة، لآخر 3 تبادلات كحد أقصى؛ ليس مشفرًا ولا يُخزن في localStorage أو D1. رفض التوقيع المعدل يمنع العميل من زرع `tool_result` أو رسالة system. يتقلص السياق الطويل تلقائيًا. عند إعادة تحميل الصفحة تبدأ جلسة جديدة.

نص السؤال العادي يُرسل إلى Claude لتوليد الرد، مع أجزاء الكتالوج أو السياسة المسترجعة. تُحذف روابط الطلب الخاصة ذات الرموز، وأرقام الهاتف المصرية المكتوبة بالأرقام الإنجليزية والبريد الإلكتروني قبل الإرسال؛ هذه ليست أداة شاملة لإزالة كل البيانات الشخصية. لا يطلب المساعد بيانات شخصية، ويُفضل توضيح استخدام الذكاء الاصطناعي ومزود المعالجة ضمن سياسة الخصوصية المعتمدة قبل إطلاقه للعملاء.

الرد يُعرض كنص ولا ينفذ HTML. البطاقات تُبنى من بيانات الأدوات، وروابطها وصورها مقيدة بمصدر المتجر. وصف منتج غير موثوق لا يفتح صلاحيات أو أدوات تعديل. دقة نص النموذج نفسه تحتاج تجربة فعلية ومراجعة حتى مع بيانات سليمة.

## التعطيل

اضبط `ASSISTANT_ENABLED=0`؛ يختفي الزر عند تحميل الصفحة ويُوقف API استقبال المحادثات. إذا أردت إعادة ضبط العداد اليومي أثناء التطوير، استخدم قاعدة التطوير فقط؛ لا تغير عدادات الإنتاج لتجاوز حد الاستهلاك.

## التحقق الذي أُجري في هذه النسخة

اختبارات Claude وTurnstile تعمل بمحاكاة ردودهما؛ D1 جرى التحقق من استعلاماته باستخدام SQLite فعلي داخل الاختبارات. لم يُجرَ اتصال Claude مدفوع أو نشر إنتاجي أو تهيئة قاعدة بيانات الإنتاج. لا توجد مفاتيح في التسليم.

اجتاز التنفيذ 16 اختبارًا للمساعد و21 اختبارًا للأسعار والطلبات والدفع ومسارات المنتجات. تحقق DOM بالمحاكاة من إظهار الزر وتعطيله، والفتح والإغلاق، والتحقق والإرسال، وعرض النص بأمان، ورفض رابط منتج خبيث. المعاينة المصوّرة في متصفح فعلي لم تكتمل لتعذر توفير متصفح الاختبار؛ فحص الموبايل في بيئة المعاينة ما زال مطلوبًا.
